GB FOUNDRY — TABLETTE

1. Ouvrir index.html dans votre navigateur pour voir le site.
2. Pour mettre en ligne sur Render Static Site : déposer index.html et logo.png dans un dépôt GitHub, puis choisir un site statique avec Publish directory '.' et aucune commande de build.
3. Cette version ne comprend ni comptes administrateurs, ni catalogue de produits, ni panier.
4. Les formulaires enregistrent uniquement dans le localStorage du navigateur. Ils NE transmettent PAS les demandes à l'entreprise et ne synchronisent PAS plusieurs appareils. Pour un service réel, connecter une API, Supabase ou un bot Discord côté serveur et ajouter une gestion de demandes sécurisée.
5. Les actualités sont des exemples modifiables dans index.html.
